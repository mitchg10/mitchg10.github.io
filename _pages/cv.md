* **DEX Disaggregated Memory Index Reproduction** (Spring 2026)
  * Empirical reproduction and stress testing of DEX (Lu et al., VLDB 2024), a B+-tree for disaggregated memory, on a 4-node CloudLab cluster for CS 6204
  * Reproduced DEX's near-linear throughput scaling across five workloads under Zipfian and uniform distributions on AMD EPYC d6515 nodes, confirming key trends from the original despite hardware differences (RoCE v2 vs. InfiniBand, single-socket vs. dual-socket)
  * Diagnosed and resolved multiple hardware-portability bugs including a NIC on-chip SRAM allocation failure requiring hugepage-backed fallback, a memcached TCP saturation bug causing silent multi-node startup failures, and an early-exit measurement issue masking valid throughput windows
  * Developed a CXL projection model using Intel MLC NUMA latency measurements and per-operation RDMA decomposition, finding minimal DEX gains under CXL ASIC because DEX's three core mechanisms compensate for RDMA-specific costs that CXL largely eliminates
