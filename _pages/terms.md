This site is a static personal academic page, and I do not collect, store, or track any personal information about visitors. There are no analytics scripts, tracking cookies, or third-party advertising services running on this site, and there is no comment system, so there is no way for visitors to submit personal information through the site.

This site is hosted on GitHub Pages. As with any web host, GitHub may log basic technical request data (such as IP address, browser type, and timestamps) as part of standard server operation; that logging is controlled by GitHub, not by me. See [GitHub's Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement) for details.

If you have any questions about this policy, feel free to [get in touch](/contact/).
